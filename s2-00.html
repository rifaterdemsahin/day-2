🧭 S2-00 Brief, hook and loop

The promise of the short, the hook and how it loops. Everything else follows from this page.

🪝 Hook (first second)

Tokens are just numbers. How does an AI know that king minus man plus woman equals queen?

🔄 Loop plan

Last line flows into the first line: '…how do these vectors talk to each other? Tokens are just numbers…'. The last frame is the same dark star-field with a lone glowing dot, which is the first frame.

🥚 Rewatch bait

Token 9246 returns as a tiny glowing dot hidden inside the Queen vector in Scene 4. Only people who watch twice spot it.

🎨 Style line (same on every Flow prompt)

Dark space, deep blue and violet, neon cyan and gold accents, clean glowing lines, cinematic slow camera, vertical 9:16, no text baked into the video (captions are added later), no people, no logos.

🔁 Rewatch rules

  1. ⚡ Hook in the first second.
  2. 🔄 Seamless loop: last line leads into the first.
  3. 🥚 One detail you only see the second time.
  4. 🎞️ A visual change every 2–3 s.
  5. 🏁 Payoff in the last third, teaser last.
  6. 💬 Captions always on, in the safe area.
