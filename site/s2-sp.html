🛰️ S2-SP Sprite setup

One-time setup of the Fly.io Sprite and the local runner behind the 🚀 button in the notes panel. Keys come from Azure Key Vault at run time (never stored on the site, the repo or the sprite). Done once on 2026-11-14; this page is the replay.

🚀 What the notes button does

Press 🚀 Run in the 📝 panel. The local runner reads the agent key from Azure Key Vault, runs the agent (kilo, claude or antigravity) on the sprite day-2 with your notes as the task, brings back a patch, applies it here, rebuilds, commits, pushes main and deploys to Fly.io. The log streams into the panel.

🔒 No secret is on the site. The key goes to the sprite only on stdin for that run, and no GitHub token goes to the sprite at all (it returns a patch). The runner listens on 127.0.0.1 only and accepts only this site's origin.

⚠️ Only your own notes should go in: they become the agent's instructions.

🔢 Steps to follow (tick each one)

  • 🔁 The runner refuses to start a run unless this repo is clean and equal to origin/main, so the patch always applies.
  • 🧾 Sprite name and folder come from assets/short.json › sprite.
